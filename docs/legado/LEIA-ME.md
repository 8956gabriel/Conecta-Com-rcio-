# Arquivo antigo (não usado)

`App-antigo-nao-usado.jsx` ficava solto na raiz do repositório. É uma versão antiga
(cerca de 4.500 linhas) do `src/App.jsx` e **não entra no site**: o build usa só
`src/main.jsx` → `src/App.jsx`.

Foi movido para cá (não apagado) em nov/2026, durante o Projeto Master, para não
confundir quem mexe no código. Pode ser apagado quando tiver certeza de que não
precisa mais dele.
